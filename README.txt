Math Final Grade Prediction - Streamlit starter

1. Add YOUR math_score_model.pkl from Google Colab to this folder.
2. Upload app.py, requirements.txt, math_score_model.pkl to the ROOT of a GitHub repo.
3. Go to https://share.streamlit.io and choose Create app > Yup, I have an app.
4. Select your GitHub repository, main branch, and app.py; then Deploy.
5. Test default inputs G1=14, G2=15, studytime=2, failures=0.

Important: Do not upload notebooks with passwords, tokens or other private information. Use only trusted .pkl files.
If scikit-learn complains about model loading, match the scikit-learn version used during training.
This implementation uses Streamlit directly and does not include FastAPI.
